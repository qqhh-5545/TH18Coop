# TH18Coop

[English](README.en.md)

东方虹龙洞本地双人、在线两至三人联机模组。支持在原版界面分别选择机体和初始卡牌、独立资源与卡牌、多人录像，以及自定义键位。

## 使用

从 Releases 下载便携包并完整解压，运行“虹龙洞联机.exe”，选择自己的游戏目录。支持受校验的日文版 th18.exe 和汉化版 th18c.exe及 Steam 1.00a；不包含游戏。Steam 版请先打开 Steam 并登录，再从联机启动器选择游戏目录。已核验 Steam EXE 版本及原生代码布局；本轮运行实测仅使用独立安装版，未启动或改动本机 Steam 游戏。

- **Local Co-op**：两个人使用同一台电脑，在原版界面依次选人、选卡。
- **Online Co-op**：主机选择2或3人并创建联机，朋友填写地址、端口、连接码后加入。每台电脑控制自己的席位。
- **键位**：分别设置本地P1、本地P2和在线本人的键盘；点击键位框后按键，保存后下次启动生效。未修改时P1与在线沿用原版键盘/手柄配置，本地P2仍为IJKL/G/F/H/U/O。Esc、Enter保留用于菜单。同机两人避免重叠，在线各端可以不同。
- **Replay**：在只允许回放的临时游戏中使用原版 Replay 列表、选关和播放功能。需要同版本多人录像；旧输入诊断不能转为录像。
- **?**：查看完整玩法和数据位置。

在线使用TCP。局域网填写主机地址；内网穿透须将TCP隧道转发到主机本地端口，默认28180。主机协商缓冲1～12帧，默认2帧；网络波动时等待精确输入，不进行预测回滚。游玩时保持联机窗口开启。

游戏开始后的短线会暂停并自动尝试原席位重连，期限30秒；恢复同一会话并补齐未确认输入后继续。启动前断线需要重新连接。不同步或重连失败时游戏保持暂停，在启动器点击“结束本局”结束，诊断保留在本次会话目录的 `session-error.txt`。这不修复已有状态差异，也不提供关卡检查点恢复。两端须完整更新同一安装包。

## 数据

所有游戏进度使用独立联机档，保留逐步解锁，不导入单人进度。custom.exe配置在启动时复制到隔离配置，原件不写。

- 长期联机档：游戏目录 `coop-data/ShanghaiAlice/th18`。
- 在线会话：`coop-data/sessions/<ID>/host`、`guest`、`guest-p3`；仅正常结束的主机备份后提交长期进度。
- 多人录像：`coop-data/replay/*.rpy`；可复制给同版本朋友观看。
- 临时观看：`coop-data/replay-sessions`；正常关闭清理，异常保留。
- 日志：`coop-data/logs`及启动器旁的`coop.log`。
- 游戏路径和本机键位：启动器旁`game-path.txt`、`keybindings.ini`，不需要发给朋友。

详细说明：[玩法](docs/COOPERATIVE_RULES.md)、[录像](docs/REPLAY.md)。汉化文字/图片沿用游戏已加载资源；修改脚本或启动链的补丁未全面验证。完整长局、全部机体卡牌组合仍需更多实测。

## 构建

Windows PowerShell、Zig0.13.0、.NET Framework C#编译器：

```powershell
./build.ps1 -ZigPath C:/Tools/zig/zig.exe
./test.ps1 -ZigPath C:/Tools/zig/zig.exe
```

构建脚本编译仓库中的原生模块和启动器，不需要提交游戏资源。测试使用模拟引擎和回环网络，不会自动启动原版游戏。

启动器的“thcrap”可选择自动读取本机 Steam 启动选项、不使用，或手动指定 thcrap_loader.exe 与汉化配置；手动设置也适用于独立版。路径仅保存在启动器旁 thcrap.ini，不随便携包分发。Steam 与 thcrap 的原始设置不改动。完整 thcrap 补丁组合仍需各自实测。
