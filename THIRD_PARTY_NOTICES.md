## th06_multi_net algorithm reference (CC0)

The fixed-delay capture/send/consume approach was studied from RUEEE/th06_multi_net, commit fd64f9f01698ca336de803d753baa2ca4e7d9131, especially Controller.cpp GetInput_Net/SendKeys/GetKeys. The TH06 implementation and UDP network classes are not copied into this mod. This adaptation retains the existing TCP transport and eagler input codec, disables prediction, and supports the existing TH18 two/three-player roster. Reference source: https://github.com/RUEEE/th06_multi_net/tree/fd64f9f01698ca336de803d753baa2ca4e7d9131 ; upstream CC0-1.0 license: https://github.com/RUEEE/th06_multi_net/blob/fd64f9f01698ca336de803d753baa2ca4e7d9131/LICENSE .
