# 多人玩法

各玩家分别选择机体和初始卡牌。残机、Bomb、火力、金钱、卡牌及冷却独立；关底商店按席位轮流操作。卡槽、可选卡牌和解锁以当前联机档为准。

| 规则 | 行为 |
|---|---|
| Boss伤害 | 仍可参战者2人时总伤害×3/4，3人时×2/3，剩1人不缩放。普通重生仍计数，幽灵不计数。只影响登记Boss。 |
| 决死 | 各机体原版窗口翻倍。 |
| 初始Bomb | 每局原生基础数量减1，最低1；额外卡牌奖励独立计算，跨关不重复减少。 |
| Bomb保护 | 每次发动给存活队友60逻辑帧保护，不缩短已有更长保护。EX的原生Bomb免疫检查全队有效Bomb。 |
| 自机狙 | 按发射/改向位置选择最近存活机体，同距离按席位；排除死亡等待与幽灵。 |
| 透明 | 队友机体、射击及部分装备靠近时淡化；剧情立绘不参与。 |
| 幽灵 | 最后一命耗尽后自动漂浮，不能自行移动、射击或拾取。保留原生动画。 |
| 分命/救援 | 20像素内停枪连按低速5次，每次间隔最多24逻辑帧。需持有备用命；优先幽灵，再选残机较少者。长按不累计，离开、开火、超时或目标变化重置。救援直接复活，否则生成只归目标的追踪生命道具。 |
| 复活 | 半满火力、自己的初始Bomb、240帧保护。过关或进入关底商店时幽灵免费复活；共享生命补给也可使其恢复。 |
| 分火力 | 20像素内连点射击5次，每次间隔最多24帧；优先火力最低的近身队友。每次转移1.00，需有完整份额，失败不扣费；赠送物仅归目标。 |
| 团灭 | 全员幽灵180逻辑帧后结束，救援后重置。不能续关，可回标题重开。 |
| 共享补给 | 残机、Bomb、对应碎片、完整灵力补给、消耗型补给卡，任意人拾取后各自按原生上限与碎片阈值结算。 |
| 普通P/金钱 | 各自拾取。普通大/小P掉落数按人数增加，优先最近未满火力者；追踪中保留归属，目标失效再分配。全部满时沿用原生处理。 |

1帧指游戏逻辑帧，60帧时约1秒。UI采用游戏当前加载的数字、文字、碎片图和卡牌ANM；主动、装备、被动卡分类，保留原生卡框、切换、使用及冷却动画。在线左下显示本人的主动卡。

本地与在线均可在启动器设置键盘。在线主机推进共用主菜单与剧情，暂停共用。存档、配置和录像位置见README与启动器“?”。
