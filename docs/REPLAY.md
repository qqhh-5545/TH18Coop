# 多人录像

正常结束一局、回标题或退出游戏时，主机会自动收藏录像；也可使用游戏原本的保存录像界面。收藏位置为所选游戏目录的 `coop-data/replay/*.rpy`。自动收藏需要正常清理游戏，异常崩溃不能保证保存当前局。

点击启动器“Replay”，进入独立临时游戏，直接显示原版 Replay 列表。按原版方式选择录像、关卡和播放；播放后可回录像列表，取消列表则关闭临时游戏。保留原版暂停、播放速度等控制。此实例不能开始普通游戏，也不提交成绩或解锁。正常关闭后清理 `coop-data/replay-sessions/<ID>/viewer`；异常时保留临时文件和日志。

可将 `.rpy` 复制给朋友，放到他游戏目录的 `coop-data/replay`，用相同版本启动器观看。需要相同核心、联机 DLL 和玩法配置；只替换文字/图片的汉化不计入玩法身份校验。原版列表一次显示最近75份符合当前版本的录像，收藏目录中的其他文件仍保留。请从启动器“Replay”观看多人文件。

旧版没有附加多人数据的 `.rpy` 和 `logs/*.th18input` 不能补回队友录像。扩展不录制桌面视频，观看不需要连接主机。回放数据不一致时停止播放，原收藏文件不改，原因写入扩展旁 `coop.log` 和临时 profile 的 `replay-error.txt`。

## 实现

原版压缩录像仍记录P1。额外数据放在原版文件头第4个字段所标记的压缩区末尾之后，不修改原版输入流、菜单、选关索引或播放状态机。多人文件使用固定宽度二进制段和校验尾标，校验版本、核心/DLL/规则身份、人数、阶段长度和输入边界。

每关保存额外机体创建时机、个人资源/资金、位置与计时、幽灵/赠送状态、完整机体射击数据校验和卡牌。卡牌沿用原生虚函数的录像导入/导出，另外记录选中ID与两组计时器的数值字段；原生指针和ANM实例不写入文件。

原版逐帧录制/播放回调读写三席位输入。场景初始化和每帧入口恢复完整随机数状态；额外机体的原生资源准备就绪后才进入其记录中的创建帧。每帧检查玩家状态，每60帧检查敌人、弹幕和掉落。校验用于发现差异，不用逐帧覆盖玩家或场景来伪装一致。

在线仍为主机协商缓冲帧的TCP精确输入同步。本功能不引入预测回滚，也不改变独立渐进解锁的联机存档规则。实机验证范围和限制见 `REPLAY_VALIDATION.json`；自动测试中的人工商店/跳关场景不代表自然通关。
