# 辉针城联机

支持辉针城 1.00b 本地双人、在线两至三人。完整解压 1.0.5 便携包，打开 TouhouCoop.exe 选择“东方辉针城”，或运行 TH14-LocalCoop.cmd，再选择自己的游戏目录和汉化/日文入口。

Local Co-op 由 P1 操作主菜单和难度，随后各席位依次选择自己的角色与 A/B 武器。Online Co-op 的主机选择人数创建联机，队友填写地址、端口和连接码加入，各端使用同一版本。默认 TCP 端口 28180，缓冲 2 帧。跨网需要可连通的 TCP 端口或内网穿透。

P1 默认沿用原版键位。本地 P2 使用 I/K/J/L 移动、G 射击、F 低速、H Bomb，启动器“键位”可分别修改本地及在线操作。菜单和剧情由 P1 操作。

生命和 Bomb 补给由存活玩家共享，幽灵无法获得道具或共享补给。普通红 P 自动吸取时优先最近的未满灵力存活玩家，同距离优先低席位号；全队满灵力时取最近玩家。线下由实际碰到的未满灵力玩家拾取，满灵力玩家碰到时可改投未满灵力队友。

有备用残机的玩家靠近幽灵约 20 像素，松开射击，快速点按低速 5 次救起。靠近未满灵力的存活队友，连续点按射击键 5 次赠送 1.00 灵力。第 3、4 次有效点按显示 L 3/5、L 4/5 或 P 3/5、P 4/5。第 5 次处理转移。再次分命需要松开低速键重新开始，每次有效点按间隔不超过 24 个逻辑帧。幽灵也可过关复活，团灭无法续关。

thcrap 按钮可指定已有 thcrap_loader.exe 与补丁配置。启用后对日文 th14.exe 应用补丁，本地和在线均生效；关闭后使用所选入口。HUD 沿用当前游戏加载的文字、数字与碎片素材。

进度保存在所选游戏目录 coop-data/ShanghaiAlice/th14，在线会话使用独立子目录，正常结束仅主机提交进度。原单人进度不导入，更新时保留 coop-data。显示设置沿用原版 custom.exe。

辉针城多人 Replay 尚未支持。偶发卡顿仍待排查，真实异地长时网络与完整组合尚未全面验证。包内不含游戏本体、汉化、thcrap 或存档。

普通协作规则参考 [Eagler Touhou](https://github.com/Ritosa2333/eagler-touhou/blob/main/launcher/content/MULTIPLAYER.md)。
